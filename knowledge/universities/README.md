# Другие вузы (кроме AlmaU)

Pro4U — независимый гид по вузам Казахстана (владелец — автор проекта, не университет).
AlmaU описан подробнее всех (`knowledge/programs/`, баллы на грант). Здесь — остальные вузы; бот их уже
использует: кнопка «🏛 Другие вузы» и ответы ИИ.

Сейчас в базе: ЕНУ им. Гумилёва (`enu`), КБТУ (`kbtu`), Нархоз (`narxoz`).

## Структура

```
knowledge/universities/<slug>/
  university.json   # о вузе: название, город, тип, оговорка о ценах, слова для узнавания (aliases)
  programs.json     # список программ: код, название, ЕНТ, ключевые предметы, профессии, где работают, цена
```

## Как добавить вуз
1. Подготовить справку в том же формате, что ENU_UNIVERSITY.pdf / KBTU_UNIVERSITY.pdf на Google Диске:
   «● Название-6B…», «Профильные предметы ЕНТ:», «Ключевые дисциплины программы:», «Траектория выпускников:»,
   «Где работают:», в конце раздел «СТОИМОСТЬ ОБУЧЕНИЯ».
2. `python tools/import_university_pdf.py справка.pdf knowledge/universities/<slug>/programs.json` —
   скрипт напечатает программы без цены или без предметов ЕНТ, их проверить вручную.
3. Создать `university.json` по образцу соседних вузов (обязательно `aliases` — как вуз пишут в вопросах:
   «кбту», «kbtu»…, строчными буквами; и `price_note` — откуда цены и насколько они точные).
4. Отправить на GitHub — Railway сам обновит бота.

## Правила
- Только короткие выжимки. Исходные PDF — на Google Диске (папка `universities/` и `*.pdf` в `.gitignore`).
- У каждого вуза — источник и дата (`source`, `checked_on`). Цены с агрегаторов помечать как ориентировочные.
- Нейтрально: без оценок «лучше/хуже», без логотипов и без выдачи себя за приёмную комиссию вуза.
