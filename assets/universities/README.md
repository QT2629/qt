# Свои фотографии вузов

Положи сюда фото с именем `<код вуза>.jpg` (или .png) — бот покажет его в карточке вуза вместо фото из Википедии.
Код вуза — как в боте: `sdu`, `kbtu`, `enu`, `almau`, `narxoz`, `mnu`, `aitu`, `satbayev`, `kazatu`,
у остальных — `u` + номер (например, `u69` — КазНУ им. аль-Фараби). Список кодов: `docs/catalog_report.md`.
Размер — до 5 МБ, лучше горизонтальное фото здания.
