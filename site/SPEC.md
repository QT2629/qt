# Сайт Pro4U — этап 1 (каталог). Техзадание

Репозиторий бота: корень этой рабочей копии (`universities.py`, `grants.py`, `knowledge/`). Сайт — папка `site/`.
Сайт **статический**: `python site/build.py` собирает HTML в `site/dist/` (папка в .gitignore). Никаких новых
зависимостей: только стандартная библиотека Python 3.12+ (html, json, pathlib, re, shutil). Бот не трогаем.

## Источник данных (единый с ботом)
```python
import os, sys
for k in ("TELEGRAM_BOT_TOKEN", "ANTHROPIC_API_KEY"): os.environ.setdefault(k, "build")
os.environ.setdefault("DATA_DIR", <временная папка>)
sys.path.insert(0, <корень репозитория>)
import universities as U, grants
U.UNIS  # dict slug -> вуз (144 шт.), уже с подставленными грантами
```
Вуз: `slug, short, name_ru, name_kz, city, region?, type?, website?, admissions? {phones[], email, address, hours, url},
notes, price_note, dorm?, admission_special? {summary, exam_name, ent_required, ent_note, eligibility, deadlines,
documents[], grants, diploma, checked_on}, checked_on?, students?, rating?, programs {code: программа}`.
Программа: `code, name_ru, section ("B057 Информационные технологии"), ent_subjects, ent_note?, price_kzt?, duration?,
languages?, key_courses[], careers[], workplaces[], tracks[], about?, outcomes?, url? (страница программы на сайте вуза),
grant_2026? {gop, count, min, kz_min, kz_count, ...}, open (показывать только open=True), not_in_reference? (программа из
реестра, нет в справке вуза — пометить «набор уточняйте»)`.
Гранты по вузу и группе: `grants.uni(slug, gop)` → `{"2026": {кат: [грантов, мин.балл] или [грантов, None, мин.%]}, "2025": …}`;
по стране — `grants.country(gop)`; название категории — `grants.label(кат)`; название группы — `grants.gop_name(gop)`.
`gop` — первые 4 символа `section`/`grant_2026.gop` (например `B057`).

## Адреса страниц
- `/index.html` — главная: поиск и фильтры (каркас; логику пишет отдельный исполнитель, см. «Поиск»).
- `/vuz/<slug>/index.html` — вуз.
- `/vuz/<slug>/<pid>/index.html` — программа; `pid` = код, где всё кроме `[A-Za-z0-9]` заменено на `-`, в нижнем регистре.
- `/osobyi-priem/index.html` — список вузов, у которых есть `admission_special`, по алфавиту.
- `/o-proekte/index.html` — о проекте: что это, откуда данные, «уточняйте в приёмной», независимость (вузы на равных).
- `/data/index.json` — индекс для поиска (формат ниже).
- `/static/style.css`, `/static/search.js`, `/static/search.css`.
Все ссылки внутри сайта — относительные от корня через префикс `BASE` (по умолчанию `""`, задаётся аргументом
`--base /pro4u`), чтобы сайт работал и в подпапке.

## Правила содержания (обязательно)
1. **Только официальные ссылки**: `website`, `admissions.url`, `programs_url`, программа `url`. Поле `source` и любые
   адреса агрегаторов (univision, studyinkz, epvo, bilim.expert, vuzopedia и т.п.) **не показывать**. Если в тексте поля
   встречается URL — не делать его ссылкой.
2. **Вузы на равных**: сортировка по алфавиту (`short`), никаких «лучший», рейтингов, звёзд, «рекомендуем».
3. На каждой странице вуза и программы — блок «Важно»: данные из справок вузов и официальных списков грантов МНВО РК;
   правила приёма меняются каждый год; сроки, цены и документы уточняйте в приёмной комиссии; дата проверки
   (`admission_special.checked_on` или `checked_on`, если есть).
4. Блок «Особый порядок поступления» — если есть `admission_special`: summary, затем поля (экзамен, нужен ли ЕНТ,
   кто может поступать, сроки, документы, гранты, диплом) — только непустые.
5. Гранты на странице программы: таблица 2026 и 2025 «в этом вузе» по всем категориям (`grants.uni`), сортировка по
   числу грантов, названия категорий через `grants.label`; если вместо балла процент — «от N% от максимального балла»;
   если балла нет — «балл в списке не указан». Ниже — по стране: общий конкурс и сельская квота (`grants.country`).
   Подпись: «Мин. балл — самый низкий балл среди получивших грант, не официальный порог».
6. Всё экранировать (`html.escape`). Никаких персональных данных.
7. Кнопка «Спросить в Telegram-боте»: `https://t.me/Pro4orU_bot?start=src_site` (метка источника — бот уже считает
   `src_` в статистике). Ставить на всех страницах.
8. Язык: русский (`lang="ru"`). Казахский — следующий этап, но поля `name_kz` можно вывести вторым названием.

## Дизайн
Аккуратный, лёгкий для чтения, mobile-first: ширина контента до 860px, отступы 16px на телефоне, крупный шрифт
(17px, межстрочный 1.55), системный шрифт, светлая и тёмная тема (`prefers-color-scheme`), один акцентный цвет
(#2f6fed), карточки с мягкой границей, хлебные крошки (Главная › Вуз › Программа), шапка с названием «Pro4U — вузы
Казахстана» и ссылками «Особый приём», «О проекте». Без внешних шрифтов, без JS на страницах вузов/программ.
`<title>` и `<meta name="description">` (до 160 символов) — из данных: вуз — «<short>: программы, гранты, поступление»
+ город и число программ; программа — «<программа> — <short>» + предметы ЕНТ и группа.

## Индекс для поиска `/data/index.json`
```json
{"generated": "ГГГГ-ММ-ДД", "unis": [
  {"slug": "...", "short": "...", "name": "name_ru", "city": "...", "type": "... или \"\"", "special": true|false,
   "url": "vuz/<slug>/",
   "programs": [{"name": "...", "code": "...", "url": "vuz/<slug>/<pid>/", "ent": "ent_subjects", "gop": "B057",
                 "gop_name": "...", "price": 1234567|null}]}
]}
```
(`url` — относительные, без начального `/`.)

## Поиск (главная)
`index.html` содержит `<div id="search-root"></div>`, подключает `static/search.css` и `static/search.js`
(`<script src="..." defer>`), и **без JS** показывает полный алфавитный список вузов со ссылками (чтобы сайт работал
без JS и индексировался). `search.js` грузит `data/index.json` и строит: строку поиска (по названию вуза, программы,
коду, городу; без учёта регистра и ё/е), фильтры: город (список из данных), предметы ЕНТ (список уникальных
`ent`), «только особый порядок поступления», группа программ (gop + gop_name); результаты — карточки вузов с
количеством подходящих программ и первыми 5 программами-ссылками; счётчик «найдено N вузов, M программ»;
состояние фильтров в адресе (`?q=&city=&ent=&special=1&gop=`), чтобы ссылкой можно было поделиться.
Скрипт должен заменить статический список, только когда данные загрузились.

## Проверки (`site/check_site.py`)
Запуск после сборки; печатает ошибки и итог «Ошибок: N»; код выхода 1 при ошибках:
1. Для каждого вуза из `U.UNIS` есть страница; для каждой open-программы — страница.
2. Все внутренние ссылки (`href`/`src`, начинающиеся не с `http`, `mailto:`, `tel:`, `#`) ведут на существующие файлы.
3. Внешние ссылки только на домены из официальных полей данных (website/admissions.url/programs_url/url программ)
   плюс `t.me`. Любой другой домен — ошибка.
4. На страницах нет слов «univision», «studyinkz», «epvo», «bilim.expert», «vuzopedia», «лучший вуз».
5. Числа грантов: для 50 случайных программ число грантов «общий конкурс 2026 в этом вузе» на странице совпадает с
   `grants.get(slug, gop, "2026", "g")[0]` (если оно есть).
6. Каждая страница — валидный каркас: `<!doctype html>`, `<title>` не пустой, `meta description`, `lang="ru"`.
7. `data/index.json` содержит все вузы и программы, все `url` в нём существуют.
