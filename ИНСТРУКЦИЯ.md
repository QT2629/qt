# Pro4U — инструкция на каждый день (Mac)

Короткая памятка: как запускать и останавливать бота, обновлять его и данные AlmaU,
что делать при ошибках. Подробности про устройство бота — в `README.md`.

---

## 1. Запустить бота

1. Откройте **Терминал** (`Cmd + Пробел` → «Терминал» → Enter).
2. Вставьте и нажмите Enter:
   ```
   cd ~/Desktop/qt && source venv/bin/activate && python bot.py
   ```
3. Бот работает, когда в Терминале появились строки:
   ```
   Pro4U запущен (модель: ..., лимит 30 вопросов к ИИ в день)
   Application started
   ```
4. **Не закрывайте это окно Терминала**, пока нужен бот. Мак не должен уходить в сон
   (Системные настройки → Экран блокировки / Аккумулятор → не переводить в сон при подключении к сети).

## 2. Остановить бота и выйти из Терминала

1. Щёлкните в окно Терминала с ботом и нажмите **`Control + C`** (Control, не Command).
   Бот остановится, появится строка ввода с `(venv)`.
2. Выйдите из «коробки» с библиотеками:
   ```
   deactivate
   ```
3. Закройте окно: `Cmd + W` или просто крестик. Если Терминал спросит «Завершить процессы?» —
   значит бот ещё работает: вернитесь к пункту 1.

После остановки бот в Telegram **не отвечает**, пока вы снова его не запустите.
История диалогов, лимиты и статистика сохраняются (папка `data/`).

## 3. Изменить настройки (`.env`)

```
cd ~/Desktop/qt && open -a TextEdit .env
```
Что где:

| Строка | Что это |
|---|---|
| `TELEGRAM_BOT_TOKEN=` | токен бота от @BotFather |
| `ANTHROPIC_API_KEY=` | ключ Claude API (`sk-ant-...`), без него ИИ выключен, кнопки работают |
| `CLAUDE_MODEL=` | `claude-haiku-4-5` — дешевле всего; `claude-sonnet-5`, `claude-opus-5` — умнее и дороже |
| `ADMISSIONS_CONTACTS=` | контакты приёмной, которые показывает кнопка «Приёмная комиссия» |
| `DAILY_AI_LIMIT=` | сколько вопросов к ИИ один человек может задать за сутки |
| `ADMIN_IDS=` | ваш Telegram ID (команда `/myid`) — для `/stats` |

Правила: после `=` без пробелов и кавычек (кроме `ADMISSIONS_CONTACTS`), сохранить `Cmd + S`,
**перезапустить бота** (бот читает `.env` только при запуске).

⚠️ Никогда не отправляйте `.env` и его скриншоты: там токен и ключ. Если они «засветились» —
перевыпустите: токен в @BotFather (`/mybots` → бот → API Token → Revoke), ключ — на platform.claude.com.

## 4. Команды бота

| Команда | Что делает |
|---|---|
| `/start` | начать заново, выбрать язык |
| `/lang` | сменить язык |
| `/reset` | забыть историю разговора |
| `/myid` | показать свой Telegram ID |
| `/stats` | статистика за сутки и 7 дней (только для `ADMIN_IDS`) |

## 5. Обновить бота до новой версии

Когда в коде что-то исправили (на GitHub):
1. Остановите бота (`Control + C`).
2. Скачайте свежую версию: https://github.com/qt2629/qt/tree/claude/vibrant-dijkstra-29jfin →
   **Code → Download ZIP** → распакуйте.
3. Скопируйте из новой папки в `~/Desktop/qt` **с заменой**: все файлы `.py`, папку `knowledge`,
   `requirements.txt`, `README.md`, `ИНСТРУКЦИЯ.md`.
   **Не трогайте** `.env`, папки `venv` и `data`.
4. Если менялся `requirements.txt`:
   ```
   cd ~/Desktop/qt && source venv/bin/activate && pip install -r requirements.txt
   ```
5. Запустите бота (раздел 1).

## 6. Обновить данные AlmaU

Все данные — в папке `knowledge/`:

| Что | Где |
|---|---|
| Программы бакалавриата (предметы, траектории, ЕНТ, цены) | `knowledge/programs/*.json` — файл на программу |
| Документы, даты, цены, двойной диплом (для ИИ) | `knowledge/admission.md` |
| Тексты кнопок «Документы» и «Важные даты» | `knowledge/static/*_ru.md`, `*_kz.md` |
| Общее о программах и что не подтверждено | `knowledge/almau_common.md` |
| Магистратура и докторантура | `knowledge/graduate_programs.md` |

Проще всего — прислать новые данные в чат Claude Code: он сам обновит файлы и отправит на GitHub,
после чего останется обновить бота (раздел 5). После любых изменений данных — перезапуск бота.

## 7. Проверить ответы ИИ (нужен ключ API)

```
cd ~/Desktop/qt && source venv/bin/activate
python chat_cli.py            # переписка с ботом прямо в Терминале (выход — пустая строка)
python eval_questions.py      # автопроверка на 12 типичных вопросах, в конце «Итого: X/12»
```
Эталонные ответы — в `docs/test_report.md`. Один прогон автопроверки — примерно 10–20 центов.

## 8. Расходы

- Посмотреть: команда `/stats` в боте или раздел **Usage** на platform.claude.com.
- Ориентир на Haiku: ~1 цент за ответ ИИ, 1–3 цента на абитуриента.
- Обязательно держите **месячный лимит расходов** на platform.claude.com.

## 9. Если что-то не работает

| Что видно | Что делать |
|---|---|
| `command not found: python` | использовать `python3`, либо не выполнили `source venv/bin/activate` |
| `No module named ...` | `source venv/bin/activate`, затем `pip install -r requirements.txt` |
| `No such file or directory` | не та папка: `cd ~/Desktop/qt` |
| `CERTIFICATE_VERIFY_FAILED` | Finder → Программы → Python 3.x → дважды `Install Certificates.command` |
| `InvalidToken` | неверный `TELEGRAM_BOT_TOKEN` в `.env` |
| `Conflict: terminated by other getUpdates` | бот запущен ещё где-то (другое окно Терминала или сервер) — оставьте один |
| `Неверный ANTHROPIC_API_KEY` | ключ скопирован не полностью или удалён |
| `Закончились деньги на балансе` | пополнить Billing на platform.claude.com |
| Бот молчит в Telegram | окно Терминала с ботом закрыто или Мак уснул — запустить заново |
| На вопросы: «ИИ-консультант скоро заработает» | в `.env` нет ключа API |

Ошибку непонятно как решить — скопируйте последние строки Терминала (без токена и ключа) в чат Claude Code.
