# Pro4U — Professional for you

Независимый ИИ-консультант в Telegram для абитуриентов. Все вузы на равных: **AlmaU**, **SDU**, **ЕНУ**, **КБТУ** и **Нархоз** — программы, предметы ЕНТ, цены и баллы на госгрант 2026. Помогает выбрать специальность, сверить предметы ЕНТ, разобраться в стоимости, грантах и поступлении. Работает на русском и казахском, ответы пишет Claude (Anthropic API).

```
Пользователь → Telegram → bot.py → (база знаний по вузам + история) → Claude → Telegram
```

Какие трудности абитуриентов закрывает бот и на каких источниках это основано: [docs/research.md](docs/research.md).

**Памятка на каждый день (запуск, остановка, обновление, ошибки, что доделать): [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md).**

## Как устроен бот

**Меню (6 кнопок):**

| Кнопка | Что делает | ИИ? |
|---|---|---|
| 🧭 Подобрать специальность | анкета из 3 шагов кнопками (предметы ЕНТ → интересы → что важно) и один запрос к ИИ с персональной подборкой | 1 запрос |
| 🎯 Шанс на грант | предметы ЕНТ → свой балл → группы ГОП и вузы, куда с таким баллом давали грант в 2026 (✅/🟡/⚪, сколько не хватает), плюс картинка с результатом (`card.py`) и кнопка «Отправить другу» | бесплатно |
| 👤 Мой профиль | личная страница: имя, возраст, город, предметы ЕНТ, вуз и специальность, какое ЕНТ сдаёт; баллы пробных тестов и ЕНТ, график роста, где добрать баллы, сколько не хватает до гранта в выбранный вуз; напоминания о регистрации и дате ЕНТ (каждый день в 10:00 по Алматы). Хранится в `data/profiles.db` только после согласия, удаление — `/delete_me` | бесплатно |
| 📤 Поделиться ботом | пригласительная ссылка `t.me/<бот>?start=ref_<код>`; сколько людей пришло по приглашениям — в `/stats` | бесплатно |
| 📝 Мои предметы ЕНТ | пара предметов → в каких вузах есть программы → список с ценами и баллами → карточка | бесплатно |
| 🏛 Вузы и цены | вуз → предметы ЕНТ → программы с ценой и баллом на грант → карточка | бесплатно |
| 📄 Документы, 📅 Важные даты, ☎️ Приёмные комиссии | общие тексты и контакты всех вузов | бесплатно |

- На любой свободный вопрос отвечает Claude. Бот отправляет ему постоянную часть базы (правила, краткий список всех 31 программы, поступление — кэшируется на 1 час) и **подробные данные только тех программ, о которых идёт речь** (до 6). Так каждый запрос в разы дешевле.
- **Лимит:** 30 вопросов к ИИ в сутки на человека (`DAILY_AI_LIMIT` в `.env`). Кнопки без ИИ не считаются.
- **Модель по умолчанию — `claude-haiku-4-5`** (самая дешёвая). Если качества не хватит — поменяйте `CLAUDE_MODEL` на `claude-sonnet-5` или `claude-opus-5`.
- В консоли после каждого ответа пишется, сколько токенов ушло и сколько взято из кэша.
- История диалога — последние 12 сообщений, хранится в памяти (после перезапуска стирается).
- История диалогов, дневные лимиты и статистика хранятся в папке `data/` и **не теряются при перезапуске**.
- **/lang** — сменить язык, **/reset** — начать разговор заново.
- **/myid** — узнать свой Telegram ID; **/stats** — статистика для администраторов (ID из `ADMIN_IDS` в `.env`): сколько людей, сколько вопросов к ИИ на человека, расходы в $, какие кнопки нажимают.

## Сколько это стоит

Ориентир на Haiku: около 1 цента за ответ ИИ; в среднем абитуриент задаёт ИИ 2–4 вопроса, остальное смотрит кнопками — примерно **1–3 цента на человека**. Точные расходы — в разделе **Usage** на platform.claude.com. Там же поставьте месячный лимит расходов.

## Данные о вузах

- **AlmaU** — 31 программа бакалавриата из 59 официальных учебных планов 2026 года (`knowledge/programs/`), плюс магистратура, документы и даты приёма.
- **SDU, ЕНУ, КБТУ, Нархоз, MNU, AITU** — справки команды (Google Диск, октябрь 2026): программы, предметы ЕНТ, ключевые предметы, траектории или профессии, цены (`knowledge/universities/`).
- **Баллы госгрантов 2026** у всех вузов — из официального списка обладателей грантов, общий конкурс без квот: по каждой группе программ (ГОП) сколько грантников выбрали вуз, минимальный балл в вузе и по стране (`knowledge/grants_2026.md`, поле `grant_2026` у программ, таблица по программам — `docs/grants_2026_by_program.md`). Коды вузов в списке: AlmaU 083, ЕНУ 013, КБТУ 421, Нархоз 021, SDU 302, MNU 174, AITU 522. ФИО из списка в бот не попадают.

**Чего пока нет** — скидки и внутренние гранты, общежития. Об этом бот честно отправляет в приёмную комиссию вуза.

Как добавить данные:
1. Предметы ЕНТ, цены, баллы — добавьте поля `ent_subjects`, `price_per_year_kzt`, `grant_min_score` и т.д. в файл нужной программы в `knowledge/programs/` (образец — `knowledge/examples/program.example.json`).
2. Правила поступления — впишите текстом в `knowledge/admission.md`.
3. Перезапустите бота.

## Чек-лист запуска

1. ☐ Создать бота у @BotFather и получить токен (бесплатно) — шаг 1
2. ☐ Получить ключ API и пополнить баланс (от $5) — шаг 2; в Console поставить месячный лимит расходов
3. ☐ Запустить на компьютере (шаги 3–5), написать боту `/myid`, вписать свой ID в `ADMIN_IDS`
4. ☐ `python eval_questions.py` — сравнить ответы с эталонами в `docs/test_report.md`
5. ☐ Дать боту 5–10 знакомым абитуриентам, через неделю посмотреть `/stats`
6. ☐ Перенести на сервер (раздел «Запуск на сервере»)

## Шаг 1. Получи токен Telegram-бота

1. В Telegram открой [@BotFather](https://t.me/BotFather).
2. Отправь `/newbot`, придумай имя и username (должен заканчиваться на `bot`).
3. BotFather пришлёт токен вида `123456789:AAH...` — это `TELEGRAM_BOT_TOKEN`.

## Шаг 2. Получи API-ключ Anthropic

1. Зайди на <https://platform.claude.com> и зарегистрируйся.
2. Раздел **Billing** — пополни баланс (API платный, оплата за объём текста; без баланса бот ответит ошибкой).
3. Раздел **API Keys** → **Create Key** → скопируй ключ `sk-ant-...`. Он показывается **один раз**.

> Никому не отправляй ключи и не вставляй их в код. Если ключ утёк — удали его в консоли и создай новый.

## Шаг 3. Установи Python и библиотеки

Нужен Python 3.10 или новее (`python --version`).

```bash
# в папке проекта
python -m venv venv

# включить виртуальное окружение:
# Windows:
venv\Scripts\activate
# macOS / Linux:
source venv/bin/activate

pip install -r requirements.txt
```

## Шаг 4. Создай файл `.env`

Скопируй `.env.example` в `.env` (Windows: `copy .env.example .env`, macOS/Linux: `cp .env.example .env`) и вставь свои ключи:

```
TELEGRAM_BOT_TOKEN=123456789:AAH...
ANTHROPIC_API_KEY=sk-ant-...
CLAUDE_MODEL=claude-haiku-4-5
DAILY_AI_LIMIT=30
ADMISSIONS_CONTACTS="admission@almau.edu.kz\nhttps://almau.edu.kz/ru/admission/"
```

## Шаг 5. Запусти бота

```bash
python bot.py
```

В консоли появится `Pro4U запущен (модель: claude-haiku-4-5, лимит 30 вопросов к ИИ в день)`. Бот работает, пока открыто это окно. Остановить — `Ctrl+C`.

## Шаг 6. Проверь, что ответы идут от Claude

1. Открой своего бота в Telegram, нажми **Start** и выбери язык.
2. Нажми «🧭 Подобрать специальность» или напиши: «Мне 16, люблю рисовать и придумывать проекты. Что мне подойдёт?»
3. В консоли должны появиться строки:
   ```
   INFO | pro4u | Чат 12345 [ru] программы [...]: Мне 16, люблю рисовать...
   INFO | pro4u | Токены: вход ..., (из кэша ...), ответ ...
   ```
4. Дополнительно: на <https://platform.claude.com> в разделе **Usage** появятся запросы.

Если что-то не так — смотри на `ERROR` в консоли:

| Что в консоли | Что делать |
|---|---|
| `Не найден ANTHROPIC_API_KEY` или `TELEGRAM_BOT_TOKEN` | нет файла `.env` или он не заполнен |
| `Неверный ANTHROPIC_API_KEY` | ключ скопирован с ошибкой / удалён |
| `Закончились деньги на балансе` | пополни Billing |
| `telegram.error.InvalidToken` | неверный токен от BotFather |
| `Conflict: terminated by other getUpdates` | бот уже запущен в другом окне — закрой лишнее |

## Проверка ответов без Telegram

- `python chat_cli.py` — переписка с ботом прямо в терминале (`python chat_cli.py kz` — на казахском). Нужен только `ANTHROPIC_API_KEY`.
- `python eval_questions.py` — автопроверка: 13 типичных вопросов абитуриентов (предметы ЕНТ, цены, баллы на грант, документы, программы без набора, вопросы про другие вузы, казахский язык). В конце — сколько проверок пройдено. Запускайте после каждого изменения базы знаний или промпта. Один прогон стоит примерно несколько десятков центов.

## Запуск на сервере (чтобы бот работал круглосуточно)

Пока бот запущен на вашем компьютере, он работает, только когда компьютер включён. Для постоянной работы нужен сервер. Самый простой вариант для новичка — **Railway** (платно, примерно от 5 $ в месяц):

1. Зарегистрируйтесь на <https://railway.com> через GitHub.
2. **New Project → Deploy from GitHub repo** → выберите репозиторий `qt` и нужную ветку.
3. Railway сам найдёт `Dockerfile` и соберёт бота.
4. Добавьте **Volume** (постоянный диск) с путём `/app/data` — там бот хранит историю, лимиты и статистику. Без него всё будет обнуляться при каждом перезапуске сервера.
5. Во вкладке **Variables** добавьте `TELEGRAM_BOT_TOKEN`, `ANTHROPIC_API_KEY` `ADMIN_IDS` и при желании `CLAUDE_MODEL`, `ADMISSIONS_CONTACTS`, `DAILY_AI_LIMIT` (файл `.env` на сервер не загружается — ключи задаются здесь).
6. Нажмите **Deploy**. В логах должно появиться `Pro4U запущен`.

Важно: бот должен быть запущен **только в одном месте**. Если он работает на сервере, не запускайте его одновременно на компьютере — Telegram выдаст ошибку `Conflict`.

Подойдёт и любой другой хостинг с Docker или обычный VPS (например, казахстанские PS.kz, Hoster.kz): там достаточно `git clone`, создать `.env`, `pip install -r requirements.txt` и запустить `python bot.py` как сервис.

## Сроки ЕНТ для напоминаний

Даты лежат в `knowledge/ent_schedule.json`. Сейчас там ориентир по образцу 2026 года (`"confirmed": false`, бот пишет «ориентировочно»).
Когда НЦТ (testcenter.kz) объявит официальные сроки, поменяйте даты и поставьте `"confirmed": true` — бот перестанет писать «ориентировочно».
У каждого пользователя можно указать свою дату ЕНТ (кнопка «🗓 Дата моего ЕНТ») — о ней бот напомнит за 7, 3 и 1 день, а на следующий день попросит внести баллы.
