# Pro4U — Professional for you

ИИ-консультант в Telegram для абитуриентов **AlmaU** (Almaty Management University). Помогает выбрать специальность, сверить предметы ЕНТ, разобраться в стоимости, грантах и поступлении. Работает на русском и казахском, ответы пишет Claude (Anthropic API).

```
Пользователь → Telegram → bot.py → (база знаний AlmaU + история) → Claude → Telegram
```

Какие трудности абитуриентов закрывает бот и на каких источниках это основано: [docs/research.md](docs/research.md).

## Структура проекта

```
qt/
├── bot.py               # запуск бота, кнопки, обработка сообщений и ошибок
├── claude_client.py     # запрос к Claude API
├── prompts.py           # system prompt: роль, правила точности, стиль
├── knowledge.py         # загрузка базы знаний из папки knowledge/
├── texts.py             # тексты кнопок и сообщений (рус / қаз)
├── config.py            # настройки из .env
├── knowledge/
│   ├── programs/            # 31 программа бакалавриата, по файлу на программу
│   ├── almau_common.md      # что общее для всех программ + чего нет в учебных планах
│   ├── graduate_programs.md # список магистратуры и докторантуры
│   ├── admission.md         # ← СЮДА правила поступления, сроки, документы
│   └── examples/program.example.json   # образец файла программы
├── docs/research.md     # трудности абитуриентов и функции бота
├── requirements.txt
├── .env.example         # образец файла с ключами
└── .gitignore
```

## Как устроен бот

- **/start** — выбор языка (🇷🇺 / 🇰🇿), потом меню из шести кнопок: подобрать специальность, специальности AlmaU, мои предметы ЕНТ, стоимость и гранты, как поступить, приёмная комиссия.
- Кнопки превращаются в готовый вопрос к ИИ. Можно и просто писать своими словами.
- Бот передаёт Claude **базу знаний AlmaU** из папки `knowledge/`. Все факты об AlmaU Claude берёт только оттуда. Если чего-то нет — честно говорит и отправляет в приёмную комиссию.
- История диалога — последние 20 сообщений, хранится в памяти (после перезапуска стирается).
- База знаний кешируется на стороне Anthropic (prompt caching), поэтому повторные запросы дешевле.
- **/lang** — сменить язык, **/reset** — начать разговор заново.

## Данные AlmaU

База собрана из 59 официальных учебных планов AlmaU на 2026 год поступления (папка «стартап 1» на Google Диске):

- **31 программа бакалавриата** — подробно: код, школа, степень, срок, траектории, ключевые предметы, практика (`knowledge/programs/`).
- **Магистратура и докторантура** — пока только список по названиям файлов (`knowledge/graduate_programs.md`).

**Чего в учебных планах нет** и что нужно добавить, чтобы бот отвечал на эти вопросы: профильные предметы ЕНТ, стоимость, скидки и гранты, проходные баллы, язык обучения, сроки и документы для поступления. Пока этих данных нет, бот честно отправляет в приёмную комиссию.

Как добавить данные:
1. Предметы ЕНТ, цены, баллы — добавьте поля `ent_subjects`, `price_per_year_kzt`, `grant_min_score` и т.д. в файл нужной программы в `knowledge/programs/` (образец — `knowledge/examples/program.example.json`).
2. Правила поступления — впишите текстом в `knowledge/admission.md`.
3. Перезапустите бота.

## Шаг 1. Получи токен Telegram-бота

1. В Telegram открой [@BotFather](https://t.me/BotFather).
2. Отправь `/newbot`, придумай имя и username (должен заканчиваться на `bot`).
3. BotFather пришлёт токен вида `123456789:AAH...` — это `TELEGRAM_BOT_TOKEN`.

## Шаг 2. Получи API-ключ Anthropic

1. Зайди на <https://platform.claude.com> и зарегистрируйся.
2. Раздел **Billing** — пополни баланс (API платный, оплата за объём текста; без баланса бот ответит ошибкой).
3. Раздел **API Keys** → **Create Key** → скопируй ключ `sk-ant-...`. Он показывается **один раз**.

> Никому не отправляй ключи и не вставляй их в код. Если ключ утёк — удали его в консоли и создай новый.

## Шаг 3. Установи Python и библиотеки

Нужен Python 3.10 или новее (`python --version`).

```bash
# в папке проекта
python -m venv venv

# включить виртуальное окружение:
# Windows:
venv\Scripts\activate
# macOS / Linux:
source venv/bin/activate

pip install -r requirements.txt
```

## Шаг 4. Создай файл `.env`

Скопируй `.env.example` в `.env` (Windows: `copy .env.example .env`, macOS/Linux: `cp .env.example .env`) и вставь свои ключи:

```
TELEGRAM_BOT_TOKEN=123456789:AAH...
ANTHROPIC_API_KEY=sk-ant-...
CLAUDE_MODEL=claude-opus-5
ADMISSIONS_CONTACTS="admission@almau.edu.kz\nhttps://almau.edu.kz/ru/admission/"
```

## Шаг 5. Запусти бота

```bash
python bot.py
```

В консоли появится `Pro4U запущен (модель: claude-opus-5)`. Бот работает, пока открыто это окно. Остановить — `Ctrl+C`.

## Шаг 6. Проверь, что ответы идут от Claude

1. Открой своего бота в Telegram, нажми **Start** и выбери язык.
2. Нажми «🧭 Подобрать специальность» или напиши: «Мне 16, люблю рисовать и придумывать проекты. Что мне подойдёт в AlmaU?»
3. В консоли должны появиться строки:
   ```
   INFO | pro4u | Чат 12345 [ru]: Мне 16, люблю рисовать...
   INFO | pro4u | Ответ Claude для чата 12345 получен (812 символов)
   ```
4. Дополнительно: на <https://platform.claude.com> в разделе **Usage** появятся запросы.

Если что-то не так — смотри на `ERROR` в консоли:

| Что в консоли | Что делать |
|---|---|
| `Не найдены ключи` | нет файла `.env` или он пустой |
| `Неверный ANTHROPIC_API_KEY` | ключ скопирован с ошибкой / удалён |
| `Закончились деньги на балансе` | пополни Billing |
| `telegram.error.InvalidToken` | неверный токен от BotFather |
| `Conflict: terminated by other getUpdates` | бот уже запущен в другом окне — закрой лишнее |

## Проверка ответов без Telegram

- `python chat_cli.py` — переписка с ботом прямо в терминале (`python chat_cli.py kz` — на казахском). Нужен только `ANTHROPIC_API_KEY`.
- `python eval_questions.py` — автопроверка: 12 типичных вопросов абитуриентов (предметы ЕНТ, цены, документы, программы без набора, вопросы про другие вузы, казахский язык). В конце — сколько проверок пройдено. Запускайте после каждого изменения базы знаний или промпта. Один прогон стоит примерно несколько десятков центов.

## Запуск на сервере (чтобы бот работал круглосуточно)

Пока бот запущен на вашем компьютере, он работает, только когда компьютер включён. Для постоянной работы нужен сервер. Самый простой вариант для новичка — **Railway** (платно, примерно от 5 $ в месяц):

1. Зарегистрируйтесь на <https://railway.com> через GitHub.
2. **New Project → Deploy from GitHub repo** → выберите репозиторий `qt` и нужную ветку.
3. Railway сам найдёт `Dockerfile` и соберёт бота.
4. Во вкладке **Variables** добавьте `TELEGRAM_BOT_TOKEN`, `ANTHROPIC_API_KEY` и при желании `CLAUDE_MODEL`, `ADMISSIONS_CONTACTS` (файл `.env` на сервер не загружается — ключи задаются здесь).
5. Нажмите **Deploy**. В логах должно появиться `Pro4U запущен`.

Важно: бот должен быть запущен **только в одном месте**. Если он работает на сервере, не запускайте его одновременно на компьютере — Telegram выдаст ошибку `Conflict`.

Подойдёт и любой другой хостинг с Docker или обычный VPS (например, казахстанские PS.kz, Hoster.kz): там достаточно `git clone`, создать `.env`, `pip install -r requirements.txt` и запустить `python bot.py` как сервис.
