# Как использовать Claude по максимуму

Что мешало использовать Claude в полную силу и что для этого теперь настроено.

## 1. Claude не помнил проект → `CLAUDE.md`
**Проблема:** каждая новая сессия начиналась с нуля, и Claude заново изучал бота.
**Решение:** в корне репозитория лежит `CLAUDE.md`. Claude Code читает его автоматически и в облаке, и на Маке.
В нём описано, что это за бот, где что лежит, правила данных, проверки после изменений и как с вами общаться.
**Что делать вам:** когда что-то в проекте меняется (новый сервер, новая ветка `main`, новые правила),
скажите Claude: «обнови CLAUDE.md».

**Ещё лучше:** на claude.ai откройте **Персонализация** и коротко напишите о себе: кто вы, чем занимаетесь,
что вам важно, как вам удобнее получать ответы. Это работает во всех чатах, а не только в этом проекте.

## 2. Данные устаревают → еженедельная проверка
**Проблема:** цены, сроки ЕНТ и правила приёма меняются, а бот отвечает по старым данным.
**Решение:** настроена задача по расписанию **«Pro4U: еженедельная проверка данных о вузах и ЕНТ»**,
каждый понедельник в 11:17 по Алматы. Claude сам проверяет в интернете:
- объявил ли НЦТ официальные даты ЕНТ (сейчас в `knowledge/ent_schedule.json` даты ориентировочные);
- цены у 9 вузов с подробными данными;
- новости о правилах приёма, грантах и квотах.

Если что-то изменилось, он обновляет файлы в отдельной ветке с источниками и присылает ссылку на pull request.
Вы смотрите и нажимаете «Merge». Если ничего не изменилось, он ничего не трогает.
Уведомление о результате придёт на телефон.

**Где управлять:** claude.ai → Code → раздел с задачами по расписанию. Там можно поменять время, выключить задачу или запустить её сейчас.

## 3. «Битва 100 ботов» почти не даёт новых мыслей → разбор с вашим контекстом
**Проблема:** 100 копий одной модели думают похоже и ничего не знают о вас.
**Решение:** в Claude Code на Маке появились три команды. Они работают в рамках подписки, ключ API не нужен.

| Команда | Что делает |
|---|---|
| `/idea-review моя идея` | Сначала задаёт вам вопросы (бюджет, время, навыки, связи), потом жёстко разбирает идею: риски, конкуренты, экономика. Даёт 10 вопросов для живых клиентов и тест спроса на 7 дней. |
| `/battle моя идея` | Битва 12 субагентов: эволюция, турнир, жюри. Подходит, чтобы быстро набросать варианты. |
| `/stats-review` | Разбор статистики бота из `data/stats.db`: воронка, где люди уходят, что улучшить. Запускать на Маке, где работает бот. |

Порядок, который работает лучше всего: сначала `/battle` для вариантов, потом `/idea-review` для победителя,
потом 10 разговоров с живыми людьми.

**Как включить команды:** они лежат в `.claude/commands/` и работают, если запустить `claude` в папке проекта.
Чтобы они работали в любой папке на Маке, один раз скопируйте их к себе:

```bash
mkdir -p ~/.claude/commands && cp ~/Desktop/qt/.claude/commands/*.md ~/.claude/commands/
```

## 4. Изменения сразу попадают к пользователям → pull request
**Проблема:** если бот на Railway, всё, что попадает в основную ветку, сразу видят абитуриенты.
**Решение:** в `CLAUDE.md` записано правило делать изменения в отдельной ветке и предлагать pull request.
Вы смотрите разницу на GitHub и одной кнопкой принимаете.
**Следующий шаг (по желанию):** сделать ветку `main` основной (GitHub → Settings → Branches),
вместо `claude/vibrant-dijkstra-29jfin`. Claude может подготовить это вместе с вами.

## 5. Качество ответов не проверяется → проверки после изменений
**Решение:** в `CLAUDE.md` записано, что после изменений Claude запускает бесплатную `tools/check_names.py`,
а при изменении промпта или базы знаний и при наличии ключа ещё и `eval_questions.py`. Он сравнивает результат
с прошлым прогоном и добавляет проверочный вопрос для каждой новой функции.

## 6. Параллельная работа
В Claude Code на claude.ai можно открыть несколько сессий одновременно: одна чинит ошибку, другая добавляет
новый вуз, третья проверяет гранты. Каждая работает в своей ветке. Давайте каждой одну понятную задачу.

## Ещё идеи на будущее
- **Дашборд статистики:** страница с графиками пользователей, вопросов и расходов, которую можно открыть с телефона.
  Нужны данные из `data/stats.db`: проще всего после переноса бота на сервер.
- **Новые вузы из Google Диска:** Google Диск подключён, поэтому достаточно сказать «добавь вуз X из папки на Диске».
- **Ответы на вопросы, на которые бот не знает ответа:** собирать такие вопросы (без личных данных) и раз в месяц
  дополнять базу знаний.
