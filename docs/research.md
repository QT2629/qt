# Трудности абитуриентов и функции бота Pro4U

Короткий обзор открытых источников о выборе специальности в Казахстане. Это **не систематический мета-анализ**: публикаций мало, цифры в разных источниках расходятся. Перед тем как ссылаться на эти цифры в презентации, откройте первоисточники.

## Как бот отвечает на каждую трудность

| Трудность абитуриента | Что делает бот |
|---|---|
| «Не знаю, кем хочу быть» | Кнопка «Подобрать специальность»: ИИ задаёт по 1–2 вопроса об интересах и предлагает 2–4 программы AlmaU с объяснением |
| «Выбираю под грант / как скажут родители» | ИИ помогает отделить свой интерес от чужих ожиданий и готовит аргументы для разговора с родителями |
| «Подходят ли мои предметы ЕНТ» | Кнопка «Мои предметы ЕНТ»: ИИ сверяет предметы с требованиями программ из базы |
| «Хватит ли баллов, сколько стоит» | Кнопка «Стоимость и гранты»: только данные AlmaU, с указанием года и советом уточнить в приёмной |
| «Кем я буду работать» | Карьерные пути из поля `careers` каждой программы |
| «Как поступить, какие документы» | Кнопка «Как поступить»: ответ по `knowledge/admission.md` |
| «Боюсь ошибиться» / нужен живой человек | Поддержка и кнопка «Приёмная комиссия» |
| Родной язык | Русский и казахский на выбор |
