# Pro4U — памятка для Claude

Pro4U — независимый ИИ-консультант в Telegram для абитуриентов Казахстана. Он помогает выбрать специальность и вуз
(120 вузов, около 4 400 программ), посчитать шанс на госгрант, напоминает о сроках ЕНТ. Ответы пишет Claude API.
Владелец — автор проекта, не университет: **все вузы на равных, AlmaU не продвигаем**.

Подробное устройство описано в `README.md`, памятка владельцу — в `ИНСТРУКЦИЯ.md` (там же список «Что ещё нужно доделать»).

## Кто владелец и как с ним общаться
- Владелец не программист, работает на Mac, часто пишет с телефона. **Отвечай по-русски**, простыми словами,
  без жаргона. Команды для терминала давай готовыми к вставке, по одной в блоке.
- Объясняй, что изменилось для пользователей бота, а не только что изменилось в коде.
- Перед платными действиями (запросы к Claude API, `eval_questions.py`, `battle.py`) называй примерную цену.

## Ветки и выкладка
- Основная ветка на GitHub — `claude/vibrant-dijkstra-29jfin` (ветки `main` пока нет).
- Если бот развёрнут на Railway, **он сам обновляется из основной ветки**: всё, что туда попадает, сразу видят абитуриенты.
  Поэтому изменения делай в отдельной ветке и предлагай pull request, если владелец прямо не попросил иначе.
- Коммиты — на английском, коротко, в повелительном наклонении (как в `git log`).

## Структура
| Что | Где |
|---|---|
| Запуск, кнопки, обработка сообщений | `bot.py` (большой файл), `profile_bot.py` (личный кабинет) |
| Запрос к Claude, модели, отказы | `claude_client.py`; модель — `CLAUDE_MODEL` в `.env` (по умолчанию `claude-haiku-4-5`) |
| System prompt и правила точности | `prompts.py` |
| Вузы, программы, подбор для ИИ | `universities.py`, `catalog.py` |
| Гранты и квоты | `grants.py`, данные в `knowledge/catalog/grants.json.gz` |
| Тексты кнопок (рус / қаз) | `texts.py`, `knowledge/static/*_ru.md`, `*_kz.md` |
| Сроки ЕНТ для напоминаний | `knowledge/ent_schedule.json` (поле `confirmed`: подтверждены ли официально) |
| AlmaU | `knowledge/programs/*.json`, `knowledge/admission.md`, `knowledge/almau_common.md` |
| Другие вузы | `knowledge/universities/<slug>/university.json` и `programs.json` (см. README внутри) |
| Статистика | `stats.py` → `data/stats.db` (без текстов сообщений, ID захеширован) |
| Разовые сборщики данных | `tools/` (боту не нужны) |
| Битва идей (не часть бота) | `battle.py` |

## Правила для данных
- **Каждая цифра должна иметь источник и дату** (`source`, `checked_on` в JSON или ссылка в тексте).
  Цены с агрегаторов помечай как ориентировочные. Не выдумывай цифры: если данных нет, бот должен честно
  отправлять в приёмную комиссию.
- В карточках и ответах даём ссылки только на сайты самих вузов.
- ФИО из списков грантников никогда не попадают в репозиторий.
- Исходные PDF хранятся на Google Диске, не в GitHub (`*.pdf` в `.gitignore`).
- Казахские тексты меняй вместе с русскими.

## Проверки после изменений
1. `python tools/check_names.py` — бесплатно, без ключа: бот узнаёт все вузы и находит все программы.
   Должно быть «Ошибок: 0». Работает несколько минут.
2. Если менялись промпт, база знаний или подбор программ, а ключ API есть, запусти `python eval_questions.py`
   (примерно 10–20 центов). Итог «Итого: X/Y» сравни с прошлым прогоном, эталоны — в `docs/test_report.md`.
   Когда добавляешь новую функцию, добавь в `CASES` вопрос, который её проверяет.
3. `python chat_cli.py` — переписка с ботом в терминале (нужен ключ).

## Код
- Python 3.12, асинхронный `python-telegram-bot` 22, `anthropic` SDK 1.x.
- Комментарии и строки для пользователя — по-русски, имена в коде — по-английски. Пиши в стиле соседнего кода.
- Секреты только в `.env` (образец `.env.example`). Никогда не коммить `.env` и папку `data/`.
- Если поменялось главное меню, бот сам разошлёт его всем (`MENU_VERSION` в `bot.py`, текст `menu_updated` в `texts.py`).
